06 · Rules

The eight that get broken first

Do

  • Keep gold to the mark, the active/primary state, and a confirmed measurement.
  • Set every label, button and chrome string in mono, uppercase, 0.12em.
  • Separate with a 1px hairline before adding a container.
  • Keep the inset white bevel on every raised surface.
  • Say what the machine did, and let the user overrule it.

Don't

  • Introduce a second hue, an amber, or a red error state.
  • Round a corner. The 6px status dot is the only curve.
  • Lighten muted, or use it for required text.
  • Animate width, height, or layout position.
  • Use #FFFFFF for body copy; it is emphasis-only.
